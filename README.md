# 🎮 Python TCP 소켓 기반 UP/DOWN 2인 심리전 미니 게임 (GUI & CLI)

Python 표준 라이브러리(`socket`, `threading`, `tkinter`)만을 사용하여 개발된 **2인 실시간 대결 UP/DOWN 숫자 맞추기 & 실시간 심리전 채팅 게임**입니다.

두 개의 GUI 창을 띄워 실시간으로 채팅을 나누며(예: `"Player1 : ㅋㅋㅋㅋㅋㅋ"`, `"Player2 : 뭘 웃어?"`), 1~100 사이의 숫자를 먼저 맞추기 위한 치열한 심리전과 추측 대결을 즐길 수 있습니다.

### 방법 2: 터미널에서 각각 수동 실행

```bash

```

#### 2) 터미널 2: 첫 번째 플레이어 GUI 실행

#### 3) 터미널 3: 두 번째 플레이어 GUI 실행
```bash

```
> 매칭이 성사되며 게임과 실시간 채팅이 즉시 시작됩니다!

## ✨ 핵심 기능 및 심리전 시스템

1. **실시간 심리전 채팅 (Chatting System)**:
   - 턴과 상관없이 언제든지 우측 채팅창을 통해 상대방과 자유롭게 대화할 수 있습니다.
   - 예시:
     - `Player1 : ㅋㅋㅋㅋㅋㅋ`
     - `Player2 : 뭘 웃어?`
     - `Player1 : 50보다 크니까 75 가본다 ㅋㅋㅋ`
   - 내 메시지(연두색) / 상대방 메시지(분홍색) / 시스템 알림(주황색)으로 시각적으로 명확히 구분됩니다.

2. **2인 턴제 UP/DOWN 대결**:
   - 서버가 1~100 사이의 무작위 숫자를 선정합니다.
   - 두 플레이어가 번갈아가며 숫자를 추측합니다.
   - 현재 누구의 턴인지 상단 배너(초록색 불: 내 턴 / 노란색 불: 상대 턴)로 직관적으로 표시됩니다.
   - 상대방의 추측값과 UP/DOWN 판정이 실시간으로 공유되어 유용한 힌트가 됩니다.
   - 좌측 상단에 `정답 추측 범위: 35 ~ 68` 처럼 좁혀지는 범위가 자동 업데이트됩니다.

3. **차등 보너스 점수 시스템**:
   - ⚡ **빠른 정답 (1~4턴 내 정답)**: **300점** (초특급 보너스!)
   - ✨ **우수 정답 (5~8턴 내 정답)**: **150점** (우수 보너스)
   - 👍 **일반 정답 (9턴 이후 정답)**: **100점**
   - 먼저 맞춘 플레이어가 해당 라운드의 점수를 독식합니다!

4. **다시하기 (재시작) 기능**:
   - 한 라운드가 끝나면 하단의 `🔄 다시하기 (Restart)` 버튼이 활성화됩니다.
   - 양 플레이어가 모두 동의하면 누적 점수를 유지한 채 다음 라운드가 시작됩니다.

5. **예외 및 비정상 연결 종료 처리**:
   - 숫자가 아닌 값이나 1~100 범위를 벗어난 값 입력 시 팝업 경고와 함께 기회 차감 없음.
   - 한 플레이어가 창을 닫거나 종료하면 상대방에게 `"상대방이 퇴장했습니다"` 알림을 보내고 안전하게 소켓 정리.
